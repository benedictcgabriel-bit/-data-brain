2. Problem Statement

Organizations across healthcare, finance, and enterprise operations generate massive volumes of tabular CSV records. However, accessing and analyzing this data faces severe obstacles:

  • LLM Hallucination Trap: Passing tabular data to standard LLMs or vector RAG results in fabricated figures, missed records, and invented relationships.
  • Query Complexity: Traditional relational databases require precise SQL or Cypher knowledge, blocking non-technical business users.
  • Schema Rigidity: Standard relational databases require schema migrations whenever a file with new or unmapped columns arrives.
  • Lack of Verifiability: In audited environments, AI answers must have direct mathematical proof from the raw database.

3. The Solution: DATA BRAIN

DATA BRAIN bridges the gap between natural language questions and verifiable graph ground truth:

  • Asynchronous Ingestion: Ingests raw tabular data into a streaming pipeline and persists it into graph entities without hardcoded schemas.
  • Deterministic Graph Translations: Converts natural language questions into precise Cypher graph queries.
  • Guaranteed Grounding: Verifies every response against real database rows. Out-of-scope questions transparently yield an honest NOT GROUNDED response rather than hallucinations.

4. Key Features & Innovations

1. Dynamic Schema Adaptation: Ingests arbitrary CSV files with arbitrary column names, auto-detecting types (IDs, text, numbers) without schema alterations.

2. Multi-Property Attribute Resolution: Handles complex multi-attribute queries such as "give me the name, department and role of employee 4" and returns all requested properties accurately.

3. Deep Aggregation & Count Engine: Natively computes sums, averages, maximums, minimums, entity counts, and distinct listings directly in the graph.

4. Anti-Hallucination Verification: Every outcome displays a status badge: ✓ GROUNDED (FROM GRAPH) for verified answers, or ✗ NOT GROUNDED for unverified questions.

5. Clean Glassmorphic UI/UX: Features a playful letter-by-letter brand drop animation, soft pastel luminous styling, separate Upload and Chatbot sections, and dynamic suggestion chips.

7. User Journey / Step-by-Step Flow

  1. Interactive Intro: User opens link and experiences the letter-drop brand animation, followed by the screen sliding upward to unveil the app.
  2. CSV Upload: Drag-and-drop any CSV dataset in the Upload tab and view immediate 5-row preview and dimensions.
  3. Asynchronous Ingestion: Click Upload & Ingest and observe live progress tracking (Queued ➔ Loading ➔ Complete).
  4. Querying in Chatbot: Switch to the dedicated Chatbot screen with dynamic suggestion chips derived from uploaded columns.
  5. Grounded Responses: Ask analytical or multi-property queries (e.g. "name, department and role of 4") and receive verified, grounded answers.
  6. Anti-Hallucination Proof: Ask out-of-dataset questions to verify the transparent ✗ NOT GROUNDED response.

8. Conclusion & Impact

DATA BRAIN redefines how organizations interact with tabular data. By replacing probabilistic guessing with deterministic graph verification, it provides non-technical users with instant, transparent, and trustworthy analytical intelligence from any CSV file.
